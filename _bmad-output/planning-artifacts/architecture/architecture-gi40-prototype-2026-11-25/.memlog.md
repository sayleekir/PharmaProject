- (decision) Paradigm: layered static client (data -> domain -> app). No framework: vanilla ES modules; Vite for dev/build, Vitest for tests. Reason: prototype, no server, minimal dependency surface.
- (version) vite 8.3.8, vitest 5.1.2, jsdom 31.0.1 verified on npm 2026-11-25.
- (decision) All persistence is localStorage behind src/domain/storage.js; keys prefixed pps_. No cookies.
- (decision) Leaflet content is data, rendered verbatim; transformations (translate/summarise) are forbidden by rule.
- (decision) Browser capabilities (speech recognition, speech synthesis, camera/file) accessed only through src/app/capabilities.js with feature detection and fallbacks.
- (constraint) Artifact/hosted preview blocks camera, mic, print and window.open; features must degrade gracefully.
- (question) Real back end API shape for leaflet lookup and request submission is not decided; adapter boundary reserved in src/data/.
